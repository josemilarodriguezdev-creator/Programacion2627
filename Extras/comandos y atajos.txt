COMANDOS GIT
git clone url . -> clonar el repositorio en la carpeta sin el nombre del repositorio (sin el punto se crea una carpeta con el nombre del repositorio)
git init -> cuando iniciamos un git vacio esto es para iniciarlo
git remote add origin url -> para unir el git con el repositorio (el origin es el alias q le damos)
git pull origin main -> para traer todo el contenido de origin (el repositorio)
git status -> para ver el estado de los ficheros (rojo (hay cambios no confirmados (add)), verde (cambios confirmados(commit)))
git add nameFile -> para confirmar los cambios de un fichero en concreto
git add . -> para confirmar los cambios de todos los ficheros
git commit -m "text" -> para empaquetar todos los ficheros (con mensaje obligatorio, sino se pone te lo abre para escribir)
git push origin main -> para enviar al origin
touch nameFile.txt nameFile.java (para crear ficheros directamente con su terminacion)
touch .gitignore (un fichero para q git ignore el contenido)
git diff -> para ver los cambios que se ha hecho antes de guardar
git diff --staged -> para ver los cambios que se han hecho en toda la caja antes del stage (antes de hacer el commit)
